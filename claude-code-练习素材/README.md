# 练习素材说明

这些文件配合 [`../Claude-Code-非编程任务学习指南.md`](../Claude-Code-非编程任务学习指南.md) 第 5 章使用。
**全部是虚构的练习数据**，可以随意修改、删除、重跑，弄坏了不要紧。

## 怎么用

```powershell
# 进入这个文件夹，然后启动 Claude Code
cd "$env:USERPROFILE\Documents\DSH-EX2\claude-code-练习素材"
claude
```

然后把指南里对应练习的"复制这段"粘进输入框即可。

## 文件对照

| 文件 | 是什么 | 对应练习 |
|---|---|---|
| `会议速记-原始.md` | 带时间戳、口语化、话题来回跳的会议速记 | 练习 1：整理成会议纪要 + 决议事项表 |
| `客户反馈.csv` | 30 条客户反馈（日期 / 渠道 / 产品线 / 评分 / 内容）| 练习 2：统计分析 + 问题归纳 |
| `乱文件名\` | 5 个名字混乱的小文件（内容正常，名字很乱）| 练习 3：批量重命名 + 生成改名记录 |
| `产品介绍-草稿.md` | 冗长、空洞、堆形容词的产品文案 | 练习 4：压缩改写，多版本对比 |
| `杂乱笔记.txt` | 结构混乱的读书笔记草稿（有疑问、有待办、页码没记）| 练习 5：整理成结构化笔记 |

## 小建议

- 练习会产生新文件（如 `会议纪要-0317.md`），那是**预期结果**，不是出错。
- 想从头再练一遍：把生成的新文件删掉即可，原始素材不用动。
- 练习 2 需要 Python（本机已有 3.12）。指南里刻意要求只用标准库，因为本机没装 pandas。
